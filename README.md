# 🎃 Candy Corn Board Optimizer

Калькулятор для Halloween Part 3: показывает самый быстрый порядок покупок
**Candy Corn Gain**, **Generator Speed** и **Generator** до последнего улучшения борда
(Gain 25/25 и Speed 20/20).

Чистый статический сайт (HTML + CSS + JS, без сборки и зависимостей) — работает на GitHub Pages как есть.

## Как пользоваться

1. Введи текущие Candy Corn и CC/s.
2. Для каждого улучшения — текущий уровень и цену следующего уровня (как в игре: `25B`, `1.5Qa`, `2e12`).
3. Покупай по порядку из «Следующая покупка» и жми **«Купил ✓»** — уровни, цены и CC/s обновятся сами.
   Если что-то разошлось с игрой — просто поправь поле.

Ввод сохраняется в браузере. «Экспорт / импорт» переносит его на другое устройство.

## Модель

| Улучшение       | Множитель за уровень | Рост цены | Максимум |
|-----------------|----------------------|-----------|----------|
| Candy Corn Gain | ×1.25                | ×2        | 25       |
| Generator Speed | ×1.1                 | ×2.5      | 20       |
| Generator       | ×(1 + 1/ур.)         | ×1.3      | ∞        |

- Множители перемножаются: CC/s = база × 1.25^Gain × 1.1^Speed × уровень генератора.
- Покупка делается сразу, как хватает Candy Corn.
- Поиск точный: динамическое программирование по всем состояниям (уровни трёх улучшений),
  то есть перебираются все порядки покупок. Генератор качается ровно столько, сколько ускоряет финиш.
- Порядок не зависит от CC/s — от него зависит только время.

Множители, рост цен и максимумы можно поменять в разделе «Множители и рост цен».

## Выложить на GitHub Pages

1. Создай публичный репозиторий на GitHub, например `candy-corn-optimizer`.
2. Залей в корень репозитория файлы `index.html`, `style.css`, `calc.js`, `app.js`
   (можно через **Add file → Upload files** прямо на сайте GitHub).
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт будет на `https://<твой-логин>.github.io/candy-corn-optimizer/`.

Через терминал:

```bash
git init && git add . && git commit -m "Candy Corn Board Optimizer"
gh repo create candy-corn-optimizer --public --source . --push
gh api -X POST repos/{owner}/candy-corn-optimizer/pages -f "source[branch]=main" -f "source[path]=/"
```
